# 知识库页面与 8120 接入说明

日期：2026-10-08。用户已确认本次演示使用 `http://192.168.10.206:8120` 的 `年会知识库` collection。

## 页面

- 左侧新增知识库入口，地址 `#/knowledge`。总览展示公司、项目、个人三类卡片、四项统计、搜索、筛选与排序。
- 公司分组初始映射到 `年会知识库`；项目、个人分别映射到 `项目知识库`、`个人知识库`。已有配置中的空集合自动补齐，非空的自定义映射保留。
- 公司、项目、个人及后续新建库统一使用 `http://192.168.10.206:8120`。进入详情自动配置该库的 collection，无需再点“连接此知识库”。切换请求串行执行，只有当前集合匹配后才显示内容，避免旧请求内容混入新库。
- 新建库自动生成 `kb_<UUID>` collection，创建后进入详情；高级设置可映射已有集合。脚本 `standalone/remote_pipeline.py` 的 `ingest_remote` 在首次有效文件入库时创建不存在的集合；仅创建本机卡片不会创建服务器集合。相同集合共享内容，分组不会建立服务器权限隔离。
- 可创建、编辑、删除本机分组及集合映射，配置保存在 renderer localStorage。类型创建后固定。不是服务器知识库 CRUD，也不会建立组织权限。
- 卡片菜单支持查看详情、编辑、删除；详情菜单支持编辑、删除。删除先弹确认框，取消不改数据；确认仅移除本机卡片及配置，删除当前库后返回总览。删除全部后显示新建入口，刷新不会恢复已删除的默认卡片。本机存储写入失败时保留卡片并显示错误。
- 删除确认框明确说明服务器集合、文件、切片与处理任务保留；后端目前没有库删除契约，因此不声称实现原型里的远端级联删除。不会通过任务取消、重建等接口模拟删除。
- 详情展示原始文件、知识切片、上传任务；支持上传队列、任务取消、切片筛选及详情、TXT/MD 分页正文阅读、知识检索及关联上下文。
- PDF、Office、媒体安全预览与下载接口尚未提供，因此这些格式只显示文件信息，不使用服务器磁盘路径作为 URL。
- 未上传样例文件、未重建或删除服务器数据。本次读取确认：服务器原件 `温总视频.txt` 的切片接口返回 `collection=年会知识库`、`count=216`。

## 实际调用接口

| 接口 | 用途 |
|---|---|
| GET `/health` | 连接状态 |
| GET `/v1/documents?category=上传文档` | 原件清单 |
| GET `/v1/documents/{doc_id}/slices` | 确认已有原件的集合归属、切片列表、数量、来源映射 |
| GET `/v1/documents/{doc_id}` | 文件详情与可读能力 |
| GET `/v1/documents/{doc_id}/content?para=…&limit=20` | TXT/MD 正文分页 |
| POST `/v1/search` | `hybrid/vector/keyword`、`expand=1`、`fold_adjacent=true` 检索 |
| POST `/v1/process/async` | 上传原件并处理入库，显式指定 collection |
| GET `/v1/jobs`、GET `/v1/jobs/{job_id}` | 本机已绑定的任务记录与状态 |
| GET `/v1/jobs/{job_id}/events` | SSE 更新，断流转轮询 |
| POST `/v1/jobs/{job_id}/cancel` | 取消本机已绑定的真实任务 |

全部远程调用经 typed Preload → Electron Main → HTTP；没有 renderer 直连、硬编码 API Key 或修改服务器代码。

## 已有服务器文件的展示规则

8120 文件清单没有知识库归属字段。Main 对未绑定原件读取该 doc_id 的切片接口，仅当返回 doc_id、collection 和切片数量一致时，纳入当前集合。其他集合、没有切片、无法确认归属的原件不自动混入列表。

自动扫描单次最多 200 个原件、同时最多 3 个请求；显示未确认数量，统计是已确认文件范围，不宣称工作区全量。归属证据在 Main 短期缓存，配置身份改变后不复用。只有已确认 doc_id 才可以请求正文与详情。

服务器已有文件不伪造本机上传记录或任务 ID。无法关联真实任务时，只能显示“切片已生成”，不推断“任务完成”或“可检索”。检索来源只通过已验证切片来源的唯一映射打开，不从文件名猜 doc_id。

## 与原型的差异

保留卡片、统计、双 Tab、表格、弹窗和右侧抽屉的结构；不复制原型虚构的数千份文件、增长百分比、权限、同步和综合回答。

公司、项目、个人目前是本机展示分组。服务器库列表、组织权限、跨设备同步、完整 CRUD 仍需要知识库业务接口。
