# KLA Workstation 下一版本 MVP 需求文档

> 本文只描述产品需求、用户价值、范围和验收标准，不描述具体代码实现。
> 基线：`docs/CURRENT_PRODUCT_FUNCTIONS.md`、`docs/ARCHITECTURE.md`
> 排除：演示群聊、固定剧本、演示角色、演示台词和演示材料。

## 1. 版本目标

将 KLA Workstation 从本地优先的知识与成果处理工具升级为支持服务端知识、算力统一管理、细粒度权限和可扩展智能体生态的协同工作站。

## 2. MVP 范围

### 2.1 服务端知识能力

- 文件、OCR/解析、标准化全文、切片、向量化和检索统一迁移到服务端。
- 用户上传文本类测试文件后，能够完成知识化并在前端按权限检索。
- 支持全文读取和语义检索；用户明确要求依据整份文件时，优先提供完整文件内容。
- 输出文件、任务记录、检索记录和内容版本统一记录在服务端。
- 知识处理过程可查看状态、失败原因、重试结果和来源。

### 2.2 记忆分层

- 短期记忆保存在本地，用于当前对话、任务上下文、临时草稿和界面恢复。
- 长期记忆保存在服务端，用于用户偏好、项目事实、任务摘要和可复用经验。
- 只有任务完成、用户确认或系统判定具有长期价值的信息才可从短期提升为长期记忆。
- 长期记忆必须可追溯、可更正、可删除，并带有作用域和权限。

### 2.3 算力模块

- 服务端部署 sub2api 中转站。
- 工作站提供算力模块，展示模型、路由、用量、配额和结算信息。
- 用户、项目、群聊、智能体和任务维度的模型用量可追溯。

### 2.4 权限管理

用户只能读取和操作自身权限范围内的企业、项目、群聊、知识库、文件、成果、记忆、智能体和技能。权限至少覆盖读取、写入、执行、管理、导出，并适用于文件、知识检索、智能体/MCP 调用、成果发布、长期记忆以及算力配置。

### 2.5 预置智能体

1. **统筹智能体**：理解目标、判断任务复杂度、拆解任务、安排并行/串行协同并汇总结果。
2. **文档编写智能体**：由现有本地执行智能体更名，负责知识检索、整文读取、调研、模板使用、文档生成和基础验收。
3. **PPT 智能体**：负责演示结构、内容、模板和 PPT/PDF 产出。
4. **数据分析智能体**：负责数据读取、清洗、统计、图表和分析结论。

市场调研首版作为文档编写智能体的技能提供；是否拆成独立智能体，待后续依据权限、连接器和算力预算决定。

### 2.6 默认技能、MCP 与学习

- 预置智能体安装后自带默认技能。
- 支持注册、授权、启用、停用和审计标准化 MCP 外部技能。
- 智能体可在会话内适应；用户确认后的偏好可形成长期记忆；执行轨迹可形成技能改进草稿。
- 生产技能、权限和系统身份不能被模型无审批直接修改，学习结果需要确认发布和回滚。

## 3. 页面信息架构

左侧主菜单调整为：

1. **概览**：项目、任务、知识处理、算力、待办和最近活动。
2. **群聊**：按项目组织群聊；点击项目进入项目看板，点击群聊进入会话。
3. **知识库**：企业、项目、个人知识库，包含文件、处理队列、检索和权限信息。
4. **智能体市场**：官方智能体、组织共享、外接 MCP、自定义智能体和技能。

原项目、操作、会议、设置能力保留数据和兼容路由；项目能力主要并入群聊项目树和概览，操作/会议作为项目或群聊资源，设置收敛为账户与管理入口，最终菜单位置另行评审。

## 4. MVP 用户闭环

- 知识：上传文件 → 服务端处理 → 查看状态 → 按权限检索/全文读取 → 在任务中引用 → 生成服务端成果。
- 算力：选择模型 → 智能体调用 → sub2api 转发 → 返回结果 → 记录用量 → 展示配额和结算数据。
- 协同：用户提出需求 → 统筹判断简单或复杂 → 直接回答或生成任务清单 → 委派智能体 → 并行/串行执行 → 汇总交付。

## 5. 验收标准

1. 真实文本文件可完成服务端知识化、向量检索并展示来源。
2. 处理中或失败文件不会被误认为可检索，失败支持重试。
3. 用户无法读取无权项目的文件、切片、成果和长期记忆。
4. 至少一次真实模型调用经 sub2api 完成并可查看用量明细。
5. 新菜单可完成项目/群聊创建、简单问答和复杂委派。
6. 文档编写、PPT、数据分析智能体可完成最小任务闭环。
7. 默认技能可用，外部 MCP 可注册、授权、调用和撤销。
8. 学习产物不会绕过审批直接修改生产技能或权限。

## 6. 待定范围

服务端部署形态、身份体系、对象存储/向量库选型、sub2api 版本与授权、PPT 引擎、数据分析沙箱、市场调研智能体拆分、学习审批人及操作/会议/渠道的最终菜单位置。
