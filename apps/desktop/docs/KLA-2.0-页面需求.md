# 鲲擎 2.0 前端页面需求（首版）

## 范围与状态

本轮覆盖登录、首页、项目、群组/群聊、知识库，以及算力仪表盘、API 密钥、使用记录、模型广场和我的模型。设计来源为 Figma 文件 `8nP3MeOjbuwyg7emE7eJMO`，节点分别是 `3:2`、`2:5621`、`2:5290`、`2:4618`、`2:4984`、`2:4255`、`2:3571`、`2:2777`、`2:1961`。我的模型与模型广场链接均指向 `2:1961`，本轮将其作为模型广场的已选用子视图。页面响应式适配宽屏和窄屏；业务数据暂为前端 mock，不能视为真实账户、余额或处理结果。

## 登录

- 支持个人/企业身份登录方式切换，账号、密码必填；支持密码显隐和记住登录状态。
- 成功后进入首页，退出后返回登录页。正式版需替换为服务端身份鉴权、身份列表与默认身份选择；密码不应落盘或写入日志。
- 忘记密码、登录失败、锁定、验证码和服务不可用需由后端协议及设计补充。本预览只校验非空，不验证凭据。

## 首页

- 展示身份问候、服务状态、核心模型、Token、应用、知识和记忆摘要。
- 工作入口支持输入任务、常用提示词、跳转群聊；展示待办任务和推荐群组。
- 指标按当前身份及权限返回，刷新、空态、错误态需在正式接入时处理。任务下发与文件上传由群聊及任务接口承接。

## 项目

- 二级列表支持搜索、选择与创建项目；主视图展示项目说明、进度、成员、任务趋势与动态。
- 项目数据必须按身份/租户隔离；成员、群聊和知识关联以服务端权限为准。
- 创建时项目名称必填，描述可选。当前趋势和节点为示意数据；正式版需支持分页、编辑、归档和任务节点详情。

## 群组/群聊

- 二级列表支持搜索、创建和选择群组；新群组可关联项目。
- 会话展示发送者、时间、内容；输入框 Enter 发送、Shift+Enter 换行。当前消息仅存在运行时内存中，刷新后恢复 mock 初始值。
- 正式版应支持历史分页、实时推送、消息去重、附件上传、@成员/智能体、发送中与失败重试、文件权限和多成员协同。智能体回复不可由前端伪造。

## 知识库

- 展示企业、项目、个人知识范围，按权限过滤文件；支持搜索、上传入口、处理状态和文件详情入口。
- 当前文件选择只生成前端待处理记录，不上传二进制、不执行 OCR、切片或向量化。正式版需展示异步作业状态、失败原因、重试与可检索时间。
- 项目知识必须校验项目成员权限；企业知识受企业角色权限控制；个人知识仅本身份可见。智能问答须携带知识范围并由服务端再次鉴权。

## 算力

- 仪表盘展示余额、密钥、请求、费用、Token、模型/平台分布及趋势，支持时间范围筛选。
- API 密钥支持列表、筛选、创建和启停。正式版仅创建时返回一次完整密钥，列表只返回掩码值；复制当前预览掩码不代表可用密钥。
- 使用记录支持筛选和 CSV 导出。预览 CSV 使用示例数据；正式版按筛选条件从服务端导出并控制敏感字段。
- 模型广场支持搜索、分类筛选、参数查看、测速与选用；我的模型展示当前身份已选模型。预览选用仅内存状态，正式版须返回模型能力、定价、可用范围及接入状态。
- 余额及费用绝不可使用前端数值作为结算依据；服务端是唯一计量来源。

## 设置 / 智能体管理

- 按官方、外接第三方、自定义智能体分类展示角色卡，包含名称、职责、运行方式、挂载模型、技能和启用状态；支持分类切换及名称/职责搜索。
- 可新建自定义智能体，名称必填且不得重名，职责可选，选择可用模型；可在配置弹窗修改职责和模型，并在列表启停。外接连接器的真实授权、官方角色的可编辑范围及技能/权限管理需由服务端确定。
- 当前页面变更仅保存在运行时内存；刷新后还原示例数据。正式版按当前身份/租户权限返回列表，写操作需要管理权限、版本冲突处理与审计记录。未连接的第三方不应被误认为已验证可用。

## 前端交付边界

本轮不改 `server`，不实现真实鉴权、持久化、上传、知识化、智能体执行或计费。上述按钮在无服务能力时给出明确提示；创建项目/群聊/密钥等仅在本地演示。接入时可按同目录接口文档替换 mock 数据。旧页面源码保留，但 2.0 入口先进入新工作台。
