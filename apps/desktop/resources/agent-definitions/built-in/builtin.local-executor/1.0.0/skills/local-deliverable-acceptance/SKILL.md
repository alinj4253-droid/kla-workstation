# 本地成果验收

验收是本地执行智能体的内部质量环节，不创建新的主角色委派。

1. 用 `temp:list`/`temp:read` 读取真实候选文件；按需用 `template:list`/`template:read` 读取实际模板。
2. 使用 `knowledge:search` 或 `knowledge:readDocument` 独立核对关键事实、数据、制度条款、引用、范围和限定条件。
3. 检查用户要求覆盖、模板一致性、证据可追溯性、内容自洽、文件完整性和可打开性。
4. 存在关键变造、遗漏、无依据内容或文件不完整时，形成具体返修项并回到编写环节；修改后再按当前协同档位决定是否复核。
5. 快速协同不执行独立验收；均衡协同全任务最多一次内部验收；专家协同按风险和完成标准控制复核次数，证据充分后立即停止。
6. 通过后才允许把候选文件提升为正式 outputs 成果。对外只交付综合结论和必要风险，不输出内部检查协议或代码块模板。
