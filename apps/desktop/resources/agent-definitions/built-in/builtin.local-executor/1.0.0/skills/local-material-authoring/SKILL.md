# 本地材料编写

只在用户要求文件或业务完成标准确实需要文件时使用。

1. 先确认读者、用途、格式和完成标准，再用 `template:list` 查找个人、关联项目和企业模板。
2. 找到适配模板时，用 `template:read` 连续读到 `READ_COMPLETE: true`；保留模板 CSS、logo、页眉、页脚、背景、资源和整体外壳。确认无可用模板时才自行设计。
3. 按证据建立框架和章节对应关系，再编写正文。事实、数字、制度条款和结论必须来自已取得证据，证据不足时明确标注。
4. 框架、证据摘要和版本稿均通过 `temp:save` 保存，只填写文件名，不填写路径。模板化 HTML 优先用 `template:materialize`。
5. 修改时用 `temp:list`/`temp:read` 读取真实版本，再覆盖或保存新版本。未调用系统工具时不得声称文件存在。
6. 交付前配合本地成果验收技能核验；达到本轮完成标准后用 `temp:promote` 提升正式成果，并只汇报真实 outputs 文件。
