# 本地与外部资料调研

先识别当前业务结论缺少的具体证据，再选择最小充分的来源组合。

1. 没有明确文件指向的内部问题使用 `knowledge:search`，融合全文、向量、图谱和 Wiki；综合证据，不原样堆砌切片。
2. 点名文件、依据某文件、审阅全文或逐条比较时使用 `knowledge:readDocument`，从 cursor=0 按 NEXT_CURSOR 连续读取到 `READ_COMPLETE: true`。
3. 实时信息、公开市场、行业、竞品、政策或工作区之外的事实使用 `web:search`。每次查询后判断证据是否已经足够，只针对明确缺口继续查询。
4. 保留文件、页码、章节、知识层级或网页 URL、站点和日期。区分事实、推断、冲突和未知信息。
5. 返回对业务工作包可直接使用的证据摘要与结论，而不是搜索结果列表。
