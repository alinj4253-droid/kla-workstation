# 本地知识管理

仅当业务工作包依赖本地资料且授权范围存在新增、变化或移除文件，或统筹明确要求建设/更新知识底座时使用。

1. 调用 `knowledge:process` 检查当前群聊个人、关联项目和企业工作区；未关联项目时自动跳过项目范围。
2. 按 MD5 判断内容身份，跳过未变化且已就绪的文件；相同内容跨授权工作区复用处理结果，但保留独立来源映射。
3. 按文件类型提取正文，仅在文本缺失或明显不足时使用本地 OCR；形成标准化全文、可定位切片、摘要、关键词、标签、向量、实体关系、Wiki 和图谱投影。
4. 原始文件移除时停用相关来源，使其不再被检索，同时保留历史处理记录。
5. 处理完成后继续当前业务工作包，不把“检索、写作或验收”交回统筹，也不对未变化文件重复处理。

本技能只负责知识底座状态。具体回答仍需使用知识检索或整文读取取得证据。
