# 知识检索与整文读取

1. 无明确文件指向时使用 `knowledge:search` 融合全文、向量、图谱和 Wiki，综合证据而不是堆砌切片。
2. 用户点名文件、要求依据某文件、审阅整份文件或逐条比较时，使用 `knowledge:readDocument` 从 cursor=0 连续读取到 `READ_COMPLETE: true`。
3. 验收候选稿先用 `temp:list`/`temp:read` 找到并读取当前任务真实临时文件；模型文字中的路径不代表文件存在。
4. 证据必须标注个人、项目或企业层级以及文件、页码、章节或位置，不混淆不同权限范围。
4. 先判断证据是否足够，足够后停止检索；不足时明确缺口，禁止用模型常识冒充内部知识。
5. 检索只读取已知识化内容；知识化状态不足时向统筹说明覆盖范围，不自行委派知识管理智能体。
