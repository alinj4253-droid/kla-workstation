# 成果验收

1. 先用 `temp:list` 确认候选稿真实存在，再用 `temp:read` 读取完整待审稿；没有真实文件不能把模型口头路径当成成果。
2. 使用 `template:list` 和 `template:read` 独立读取实际模板，核对章节、必填字段和格式要求。
3. 对关键事实、数字、制度条款和结论逐项检索本地知识证据；明确来源文件时使用 `knowledge:readDocument` 连续读取完整正文。
4. 检查前后口径、引用、风险说明和 HTML 完整性。
5. 不通过时给出按优先级排列、可直接返修的清单；通过时说明已核验范围和仍需用户知悉的非阻断风险。
6. 使用唯一明确结论收尾：`验收结论：通过` 或 `验收结论：不通过`。
