# 材料编写

1. 识别材料用途、目标读者、交付格式、篇幅、时间范围和不可变更的数据。
2. 从知识管理结果中提取模板说明。存在模板时建立“模板要求 -> 章节/字段”的对应关系；没有模板时按材料类型自行设计框架。
3. 先列出完整章节框架，并为每章标注可用证据和仍缺信息。
4. 按框架逐章补充，不跨证据推断事实，不把检索切片原样堆砌进正文。
5. 统一术语、数据口径、时间范围、标题层级、引用与风险说明。
6. 生成完整 HTML 待审稿，通过 `review.writeDraft` 写入指定的 `.runtime/review-drafts/` 路径。
7. 返修时逐项响应验收意见，修改后重新提交同一路径，等待再次验收。
