# 混合知识检索

仅在知识管理智能体需要从已处理资料回答问题或核验结论时调用。

1. 先判断问题更依赖精确原文、语义相似、实体关系、Wiki 汇总，还是多路混合。
2. 仅检索当前群聊知识和共享知识，禁止读取其他群聊的私有知识。
3. 融合各通道排序、去除重复证据，并优先保留来源清楚的结果。
4. 对最小充分证据集执行 RAG 综合：比较、去重、处理冲突，再形成直接回答；每个关键结论必须标明来源文件和位置。
5. 不得把检索切片、相关度、通道名称或向量结果整批原样输出给用户；资料事实、合理推断与信息缺口必须清楚区分。
6. 检索本身不修改知识内容；原始文件的增量同步由知识文件处理技能负责。

需要调整通道或解释分数时，读取 `references/retrieval-policy.md`。
