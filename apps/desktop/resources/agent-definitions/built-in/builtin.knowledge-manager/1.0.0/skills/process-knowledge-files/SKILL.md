# 知识文件处理

在收到原始文件知识化、重新入库或知识底座更新任务时调用；不用于知识检索、整文阅读或业务问答。

1. 扫描当前群聊个人工作区、已关联项目工作区和企业工作区的 `original-files/`；未关联项目时跳过项目层。
2. 跳过未变化且已就绪的来源；顺序处理新增、变更或尚未完成的来源。
3. 同一 MD5 内容若已在任一允许范围完成知识化，直接复用切片、摘要、向量、图谱和 Wiki，并为当前工作区建立独立来源映射，不重复 OCR 或模型处理。
4. 常规解析无法获得有效正文时，调用技能声明的官方 `local:ocr` 工具；该工具随应用离线安装，禁止运行时下载。
5. 解析正文后并行生成 `standardized-files/<sourceId>/document.md`、清单和切片文件；标准化目录是只读知识中间产物，不参与原始文件扫描、二次知识化或普通检索。
6. 数据库切片记录精确的 `startOffset/endOffset`、标准化页码、页类型和最近章节，保证可以回溯标准化全文。
7. 原始文件删除后仅停用对应来源，不物理删除已生成记录；检索只能使用 `ready` 来源。
8. 只汇报有意义的处理结果、失败和待复核项。
