# 知识文件处理

仅在知识管理智能体需要检索、引用或重新入库知识时调用。

1. 扫描当前群聊和共享知识的 `original-files/`，比较当前版本的 SHA-256 与 MD5。
2. 跳过未变化且已就绪的来源；顺序处理新增、变更或尚未完成的来源。
3. 常规解析无法获得有效正文时，调用技能声明的官方 `local:ocr` 工具；该工具随应用离线安装，禁止运行时下载。
4. 生成带来源位置的切片、摘要、关键词、标签、本地向量、实体关系、Wiki 和可视化。
5. 原始文件删除后仅停用对应来源，不物理删除已生成记录；检索只能使用 `ready` 来源。
6. 只汇报有意义的处理结果、失败和待复核项。
