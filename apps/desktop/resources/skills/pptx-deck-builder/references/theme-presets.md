# 配色预设（每个项目按题材重新选，不要沿用别的项目）

> **为什么有这份文件**：技能包里的 `.slide` 模板是**中性骨架**，不含任何题材的色值倾向。
> 每个项目动手前，先在 `DESIGN.md` 定下色池，再从模板顶部"主题区"替换常量。
> 规范只要求三件事：**≤4 个 hex**、**面积分配**（主色 ≤60% / 辅色 ≤30% / 强调 ≤10%，Hero 页 15–20%）、
> **色调统一**（同一页不出现 ≥2 套配色逻辑）。
>
> **本文只是三个取值来源之一。** 另一个来源是引擎自带的 **30 套真实主题契约**——
> 想要"别人已设计好的成熟配色"时优先看它：
> ```bash
> bash scripts/themes.sh list          # 30 套全表
> bash scripts/themes.sh palette 13    # 直接产出可粘贴的常量块
> ```
> 但注意：那 30 套 **29/30 是浅底**，且**没有游戏娱乐类**——想要深色或游戏题材，仍要落到本文的自创三步。
> 详见 [theme-library](theme-library.md)。

## 四个起点预设

### ① 中性商务浅色（最通用，没有题材倾向）

```js
const BG     = '#FFFFFF';   // 主色：页面背景
const INK    = '#1B1E23';   // 文本色（不要用纯黑 #000，投影会发闷）
const CARD   = '#F1F2F4';   // 辅色：卡片底 / 次级块
const ACCENT = '#2F6BE4';   // 强调色：≤10%，只用于焦点元素
// 中性辅助（不计入色池）
const DIM    = '#767B84';
const LINE   = 'rgba(27,30,35,0.12)';
```

适用：通用汇报、产品介绍、内部培训、方案说明。**题材不明时用这套。**

### ② 深色科技

```js
const BG     = '#0F1115';   // 不要用纯黑 #000，留一点灰度才有层次
const INK    = '#EDEFF3';
const CARD   = '#1A1D23';   // 卡片底（也可写 rgba(237,239,243,0.06)）
const ACCENT = '#4EA1FF';
const DIM    = '#858B99';
const LINE   = 'rgba(237,239,243,0.14)';
const MASK   = 'linear-gradient(90deg, rgba(15,17,21,0.96) 0%, rgba(15,17,21,0.78) 34%, rgba(15,17,21,0.30) 64%, rgba(15,17,21,0.55) 100%)';
```

适用：技术方案、AI/数据产品、发布会。深色底**必须有满版图或大色块托底**，否则显空。

### ③ 学术人文（米白纸感）

```js
const BG     = '#FAF7F0';
const INK    = '#23201B';
const CARD   = '#F0EAE0';
const ACCENT = '#8C5A3C';   // 砖棕，克制不刺眼
const DIM    = '#7A7266';
const LINE   = 'rgba(35,32,27,0.14)';
```

适用：研究报告、人文社科、课程课件。衬线气质，正文行高可放到 1.7。

### ④ 政务 / 党建红金

```js
const BG     = '#FFFFFF';   // 白底
const INK    = '#1C1917';
const MAIN   = '#9E2B25';   // 主色：标题条 / 页脚底色（面积靠块面，不靠铺满）
const ACCENT = '#C9A227';   // 强调金：≤10%
const CARD   = '#F6F1EC';
const LINE   = 'rgba(28,25,23,0.12)';
```

适用：工作汇报、政策解读、党政答辩。注意：**红色靠"条块"用，不要铺满全页**，
否则触发"强调色铺满 ≥1/3 页面"的禁忌。

## 明暗两套的写法差异

| 项 | 浅色底 | 深色底 |
|---|---|---|
| 背景 | 纯白或极浅灰 | 深灰（**不用纯黑**） |
| 文本 | `#1B1E23` 一类（**不用纯黑**） | `#EDEFF3` 一类（**不用纯白**） |
| 分隔线 | `rgba(INK,0.12)` | `rgba(INK,0.14)` |
| 卡片底 | 比背景再深一档的实色 | 半透明提亮 `rgba(INK,0.06)` 或更深一档实色 |
| 图上文字 | 遮罩要压暗到 0.55–0.7 才能读白字 | 同左，遮罩基色取背景色 |
| 卡片浮起 | `boxShadow: '0 8px 32px rgba(0,0,0,0.08)'` | `'0 8px 32px rgba(0,0,0,0.45)'` |

**文字层次一律用 `opacity`（0.55–0.88）做，不要靠引入更多灰色**——
这是"4–5 个色常量也能做出层次"的关键。

## 题材不在预设里：自创配色的自证三步

预设只覆盖常见题材。遇到游戏、音乐、潮流、体育一类没有对应预设的题材：

1. **定一个主色调与明暗基调**（例如"深墨底 + 高饱和霓虹"）。
2. **选 4 个 hex 并分配角色**：主色（背景/大色块）、文本色、辅色（≤30%）、强调色（≤10%）。
3. **写进 `DESIGN.md` 并注明面积分配与自证**：主色 ≤60%、强调色只出现在焦点元素
   （巨型数字 / 章节编号 / 关键下划线 / 图表主系列 / 主图遮罩渐变）。

**注意**：`design-principle.md` 的色彩参考表只覆盖科技金融 / 人文哲学 / 教育消费 / 政务党建四类，
**没有游戏娱乐类**——这类题材属于自创配色，必须自己配并自证，不要指望规范给现成答案。

## 与模板的关系

- 模板顶部"主题区"的默认值是**中性占位**（浅底 / 石墨 / 蓝强调），目的是**不传递任何题材倾向**。
- 替换方式：改模板顶部那 4 个色角色常量 + `DIM` / `LINE` / `MASK` 即可，**版式一行不用动**。
- 一个 deck 内所有页面共用同一套常量（复制粘贴，不要每页各写各的）。
