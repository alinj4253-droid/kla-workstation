## 1. 画布与全局母版

- **画布**：1280 × 720 px，16:9。（主题契约里的 720×405 是**点**，尺度不同，别混用）
- **页面 padding**：上下 20px，左右 60–80px。
- **默认母版（A/B/C 三区，所有内容页严格复用）**：

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px（含 padding 20） | 页面主标题（区间 32–40px）bold；右侧**禁止**任何装饰小图 |
| **B · 内容区** | 120–660px | 540px 可用 | 正文、卡片、图表、配图全部在此区 |
| **C · 页脚条** | 660–720px | 60px（含 padding 20） | 左：角标 + 项目名 13px；右：页码 `NN / N`，14px |

- **例外页**：封面、章节扉页、结语使用自定义全幅版式，省略 C 区。

## 2. 颜色系统（≤4 hex，全篇唯一色彩池）

| 角色 | Hex | 用途 |
| :--- | :--- | :--- |
| **主色 · …** | `#……` | 页面背景、大色块、底图蒙版基色 |
| **文本色 · …** | `#……` | 主标题、正文、卡片文字 |
| **辅色 · …** | `#……` | 卡片背景、图标、次级强调、图表第二系列 |
| **强调色 · …** | `#……` | 仅用于焦点元素：巨型数字、章节编号、关键下划线、图表主系列 |

**辅助中性色**（不计入色池）：`#……`（二级文字）、`rgba(…,0.12)`（边框/分隔线）、`#……`（图上白字）。

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色 | ≤ 60% | 底色 / 蒙版 / 大色块 |
| 辅色 | ≤ 30% | 卡片底纹、图标、图表次系列 |
| 强调色 | ≤ 10%（Hero 页 15–20%） | 只出现在焦点元素 |
| 中性色 / 文本 | 剩余 | 文字、页脚、边框 |

**色彩节奏**：Hero 页（P…）强调色可到 15–20%；Supporting 页强调色 ≤ 5%、辅色 ≤ 20%。
P… 与 P… 两页的色彩比例应显著高于其余页，构成全篇起伏；但**不要每页比例雷同**（差异 < 10% 属禁忌）。

### 2.2 渐变与遮罩策略

> 按本项目明暗基调决定，浅色底与深色底写法不同（对照表见 `references/theme-presets.md`）。

- **强调渐变**：`linear-gradient(135deg, … 0%, … 100%)` —— 仅用于小面积元素（下划线、角标、强调块）。**禁止大面积铺底**。
- **图上遮罩**：横跨整图铺一层渐变，左端压到 0.92–0.97 让白字可读，右端压到 0.12–0.34 露出画面。
  遮罩基色取**主色**（浅色主题下则取深灰，不用纯黑）。
- **卡片底**：浅色主题用比背景深一档的实色；深色主题用 `rgba(文本色,0.06)` + `0.5px solid rgba(文本色,0.14)`。
- **圆角**：卡片 16–20，角标 8。**浮起**：浅色主题 `0 8px 32px rgba(0,0,0,0.08)`；深色主题 `0 8px 32px rgba(0,0,0,0.45)`。

### 2.3 通用禁忌
- 同一页面出现 ≥2 套配色逻辑。
- 强调色铺满 ≥1/3 页面。
- 全篇每页色彩比例雷同（差异 < 10%）。
- 使用纯黑 `#000000` 或纯白 `#FFFFFF` 作为大面积底色（会发闷 / 刺眼）。

## 3. 字体系统（2 套字体家族）

| 家族 | 声明 | 用途 |
| :--- | :--- | :--- |
| **中文主字体** | `"Microsoft YaHei", "Noto Sans SC", "Source Han Sans SC", sans-serif` | 全部中文 |
| **数字 / 西文标注** | `"Bahnschrift", "Segoe UI", "Space Grotesk", sans-serif` | 巨型数字、年份、英文小标、页码 |

> **字体栈第一位必须是目标机器上确实存在的字体**：写不存在的字体不会报错，但会被**静默替换**，
> 而引擎**不嵌字体**，成品换机器就会变样。lint 的度量与字体无关，**它不会帮你发现这个问题**。
> 禁止全篇只用系统默认无衬线；禁止出现第三套字体家族。

### 3.1 字号层级表

> **下表数值是"待定"，必须在右列区间内按本项目题材取值。**
> 参考：高信息密度题材（术语多、字数多）取区间下限；展示型题材取上限。
> 区间来源见 `references/design-md.md`。

| 层级 | 本项目取值 | 允许区间 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | … | 60–96 | bold | 1.05 | -1 | 仅 P1 |
| 章节大字 | … | 60–80 | bold | 1.1 | 0 | 章节扉页 |
| 章节编号（巨型，低 opacity） | … | 180–300 | bold | 1.0 | -6 | 扉页背景数字 |
| 巨型数据 / 锚点 | … | 72–120 | bold | 1.0 | -3 | 数据页 / 结语 |
| 页面主标题（A 区） | … | 32–40 | bold | 1.3 | -0.5 | 所有内容页固定 |
| 副标题 / 卡片标题 | … / … | 24–30 / 22–26 | bold | 1.4 | 0 | 卡片头 |
| 正文 | … | 22–28 | normal | 1.6 | 0 | 段落 |
| 卡片正文（小） | … | 17–21 | normal | 1.55 | 0 | 三栏卡片 |
| 脚注 / 页码 | … | 14–16 | normal | 1.4 | +1 | C 区 |

**字重规则**：巨型数字统一走数字字体栈 bold；全篇正文字号与页标题字号比不低于 1:1.6。
**冲突提示**：规范同时要求"内容页正文 ≥180 字"与"正文 ≥22px"，在 540px 内容区里可能装不下。
二选一时**保字数、压字号**（并在此处注明偏离），或改版式让文字分栏承载。

## 4. 信息密度门禁

- 默认**不做极简留白型**，按标准密度执行。
- **常规内容页留白上限 ≤ 35%**；Hero 页允许 40–50%，留白必须围绕核心元素。
- 逐页下限：内容页单主题正文 ≥ 180 字；卡片组每卡 ≥ 100 字、合计 ≥ 300 字（3 卡时）；数据页 ≥ 80 字洞察。
- **容器填充率 ≥ 85%**；高度 ≥380px 的卡片正文 ≥100 字；≥480px 的卡片正文 ≥130 字。
- **底栏锚定**：卡片尾部标签条 / 引文条用 `marginTop: 'auto'` 钉底。
- **横向兄弟卡对齐**：同一行卡片三段在 y 轴上必须等高，误差 ≤ 16px。

| :- | :- | :- | :- | :- | :- | :- |
| `xxx.png` | P… | L1 | ImageGen | 1536×1024 | … | ⬜ 待核对 |

### 5.3 允许使用 SVG 的元素
时间轴、关系图、背景网格、巨型数字、角标、页码下划线——结构化 / 低语义元素。

### 5.4 素材处理
- ImageGen 产物右下角自带工具水印，统一裁掉（宽 ×88.5%、高 ×91.8%）后重命名入库。
- 竖图若用在大图位，切成 N 条横带避免过度裁切。

### 5.5 图表
P… 使用 `<Chart>`，配色取色池内颜色，`background` 取主色，`axisColor` / `legendColor` 取中性色。

### 5.6 禁忌
- 正文页禁止全屏背景图（仅封面 / 章节扉页 / 结语允许）。
- 禁止装饰小贴片塞进 A 区；禁止图片自带文字 / Logo。
- 单页图片 / 图表 ≤ 3 个，总面积 ≤ 内容区 60%。

## 7. 逐页动笔自检清单（每页提交前逐项确认）
